# UVNN 2026 Strategy Tracker

Shared action item tracker: Priorities → Objectives → Actions, with owners, regions,
target dates (with change history), monthly status, and dated update notes.

- `tracker.html` — the page, published as a claude.ai artifact:
  https://claude.ai/artifact/FdMPm2peYUEbiBrV7FrxRS
- `seed.json` — the data imported from `2026V2_UVNN_Strategy_Tracker_test.xlsx`
  (Priority 1–3 sheets; Bowler and regional tabs are not imported, since regional
  tabs are views reproduced by the Region filter).

Live data lives in the artifact's shared database, not in this repo. Editing
`tracker.html` and republishing to the same artifact URL keeps all team data.
