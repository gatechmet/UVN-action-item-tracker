UVNN Strategy Tracker - shared-drive demo
==========================================

Try it out
1. Copy UVNN-Tracker.html to a folder on the shared drive, for example
   S:\Team\Tracker\UVNN-Tracker.html
2. Double-click it so it opens in Microsoft Edge or Google Chrome.
   Firefox and Safari can't open shared folders.
3. Type your name in the bar at the top, then click "Connect to data folder".
4. Pick the same folder the HTML file is in, and click "Allow" or "Edit files".
5. The first time only, click "Load starting data into this folder". It writes
   about 180 small files into a "tracker-data" subfolder.
6. Ask a coworker to open the same HTML file from the share and connect to the
   same folder. Edits from either person appear on the other screen within
   about 6 seconds.

Day to day
- Each time you open the page, click "Reconnect" and allow access again.
  The browser asks for this every session.
- Everyone needs read and write access to the folder.
- Each action, objective, priority and note is its own file in tracker-data.
  Two people only overwrite each other if they edit the same action within
  the same few seconds.
- Don't edit or delete files in tracker-data by hand.
- Filters and views stay in your own browser tab.

If it doesn't work
- "Couldn't open that folder": your company may block web pages from writing
  to network drives. Try a local folder to confirm the page itself works,
  then ask IT.
- The page downloads instead of opening: right-click the file and open it
  with Edge.

This demo starts from a copy of the claude.ai tracker data, taken on
2026-09-30. Changes made here don't sync back to the claude.ai version.
