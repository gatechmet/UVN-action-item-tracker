UVNN Strategy Tracker - shared-folder version
==============================================

What's in the folder
  UVNN-Tracker\
    UVNN-Tracker.html     <- open this
    tracker-data\         <- all the tracker's records, plus this file

Set up (once, by the folder owner)
1. Put the UVNN-Tracker folder in the team SharePoint folder:
   https://thermofisher.sharepoint.com/:f:/s/UVNN838/IgDmdYwOVqnOQJ-ogdw80wNAAUEdyOREptgQAojpNCo-aec?e=VFnGum
2. Make sure everyone who should edit has edit access to it.

First time, for each person
1. In SharePoint, click "Sync" or "Add shortcut to My files", so the folder
   appears in File Explorer.
2. Open UVNN-Tracker.html from the synced folder in Edge or Chrome.
3. A setup screen walks through the steps. Paste the synced folder's path
   into the box (copy it from File Explorer's address bar). It's saved for
   next time.
4. Click "Click here to connect folder". In the window that opens, paste the
   path into the address bar, press Enter, click "Select folder", then
   "Edit files".

After that
- If you chose "Allow on every visit", the tracker connects by itself.
- Otherwise click "Reconnect to ..." once.

Good to know
- OneDrive syncs the files in the background, so other people's edits can
  take from a few seconds to a minute to appear.
- If two people change the same action at the same moment, OneDrive may
  keep a copy named like actions__A12-YOURPC.json. The tracker ignores
  these copies.
- Don't edit or delete the files in tracker-data by hand.
- Filters and views stay in your own browser tab.

If it doesn't work
- "has no tracker records": you picked the wrong folder. Choose the
  UVNN-Tracker folder.
- "didn't allow access": choose the folder again and allow editing.
- The page downloads instead of opening: right-click the HTML file and
  choose Open with > Microsoft Edge.
